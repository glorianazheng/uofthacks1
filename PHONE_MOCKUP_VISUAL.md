## Page Layout

Each page follows this structure:

```
┌─────────────────────┐
│ 9:41         🔋📡📶 │  Status Bar
├─────────────────────┤
│ Page Title          │
│ Subtitle            │  Scrollable Content Area
│                     │  (Cards, Lists, Forms, etc.)
│ [Content Cards]     │
│ [More Content]      │
│                     │
├─────────────────────┤
│ 🏠 🧭 ➕ ⚡ 👤     │  Bottom Navigation
│Home Explore Create… │  (Active tab in blue)
└─────────────────────┘
```

## Navigation Tabs

```
🏠 Home       → Shows active bets across all circles
🧭 Explore    → Public bets feed from friends
➕ Create     → Create a new bet (central action)
⚡ Circles    → Your friend groups/circles
👤 Profile    → Your stats & identity badges
```

---

## Key Design Choices

1. **White Background** - Clean, minimalist design
2. **Bottom Navigation** - Easy thumb access on mobile
3. **Black Phone Frame** - Realistic iPhone 16 look
4. **Notch Design** - Authentic to iPhone 16
5. **Status Bar** - Professional iOS appearance
6. **Scrollable Content** - Pages can have more content
7. **Fixed Navigation** - Always accessible

---

## Device Specifications

- **Phone Model:** iPhone 16
- **Screen Size:** 390 × 812px
- **Frame Size:** 418 × 840px (with border)
- **Display:** OLED (white background)
- **Safe Area:** Accounts for notch and home indicator
